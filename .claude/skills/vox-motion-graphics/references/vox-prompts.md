# Editorial Mixed-Media Prompt Templates

Read when choosing the style key or writing footage prompts. Adapt these templates
to the actual brief. Bracketed fields are variables to fill before submission,
not factual claims, asset identifiers or promises of generation results.

## The visual language

Editorial collage combines cutout subjects, flat color fields, paper grain,
halftone print and purposeful annotations. It should feel like a moving magazine
spread. Use texture to unify the composition and motion to explain relationships.

- Pick a limited palette with one clear accent and quiet supporting colors.
- Give the recurring subject a stable silhouette, proportions and distinguishing
  features. A yellow hatchback is the traffic example, not a global requirement.
- Use paper borders, torn edges, restrained shadows and layered depth consistently.
- Use circles/arrows to identify an object or direction, not as constant decoration.
- Render data labels and exact values as native text/graphics from verified data.
- Keep one important action legible at a time. Use anticipation, readable pauses,
  ease-out entrances and controlled camera movement. Avoid filling every second
  with a transition.

## Style sheet

Create or adapt a sheet with a material/background swatch, palette, recurring
subject, close/wide composition samples and title/body/label type treatments.
The generated image can establish materials and subject treatment. Exact type
samples can be composed separately using real fonts and words.

```text
Editorial mixed-media collage visual reference for [TOPIC].
MATERIAL: [paper tone], restrained print grain and halftone, [cutout edge treatment].
PALETTE: [background], [primary ink], [accent], [supporting colors].
SUBJECT: [recurring object's silhouette, proportions, distinctive details].
COMPOSITION: clear focal hierarchy, generous room for later editorial text,
one close view and one wider view with consistent object design.
LIGHT/DEPTH: [approved shadow and layering treatment].
No readable words, numbers, captions, logos or watermark in generated artwork.
The final typography will be placed as editable layers during assembly.
```

Pass the actual intended aspect ratio and reference role in the tool parameters.
A vertical reference does not itself set the generated video's framing.

## Shared style block

Copy the same approved block into each scene request; change the shot block below.

```text
STYLE REFERENCE: Match the attached approved style reference: [palette],
[paper/print texture], [cutout treatment], [recurring subject identity].
Keep material, object proportions, lighting and screen direction consistent
with the connected scenes. Non-photoreal editorial animation.
```

## Scene request

```text
SCENE [N]: [duration] seconds, part of [total duration] [aspect ratio] explainer.
STYLE REFERENCE: [unchanged shared style block].
EXPLANATORY PURPOSE: [one relationship this scene must make clear].
START: [composition, focal object, screen position and initial state].
ACTION: [initiating action], then [observable reaction], then [consequence].
CAMERA: [framing/movement] timed to [the reason for revealing more or less].
END / HANDOFF: [recognizable object/position/direction for the following scene].
AUDIO: [silent clean footage, or authorized native effects with no dialogue].
NEGATIVE: readable text, captions, gibberish letters, logos, watermark,
unexplained subject redesign, unrelated background action, [mechanism-specific errors].
```

Use approximate beat windows only as a production target; inspect the returned
motion to learn its actual timing. For exact frame-level annotations, titles or
holds, use the edit timeline.

## Example: close cause → wider consequence

The following is a visual example. Research the actual mechanism for the chosen
topic before narration or data labels.

```text
STYLE REFERENCE: Off-white paper, restrained halftone, yellow hatchback cutout,
quiet grey following cars, dark ink road details, matching the approved sheet.
EXPLANATORY PURPOSE: A small initial slowdown makes following drivers react.
START: Close side view of the yellow hatchback, facing right; enough surrounding
space to read its change of speed. No accident or obstruction on the road.
ACTION: The yellow car eases its speed. Allow that action to register. The next
car behind reacts, followed by another; do not trigger every brake simultaneously.
CAMERA: Widen only after the initiating action becomes visible, revealing more
of the following traffic while preserving the same yellow car and road direction.
END / HANDOFF: A wider readable queue with the yellow car still recognizable.
AUDIO: Clean footage without narration; sound design is added in the edit.
NEGATIVE: collision, backward-driving cars, road closure, changed car shape,
unexplained new lane, readable letters, logos or watermark.
```

## Example: change only the camera block

For a second framing, retain STYLE REFERENCE and object identity. Change CAMERA
to the required wider composition and adapt staging only where the new shot
requires it. Compare the approved reference with both returned clips; matching
prompt wording alone is not proof of visual consistency.

## Typography and clean-footage variants

Use a large headline for the main point, smaller explanatory text near the
relevant object, and a consistent label style. Choose positions that stay legible
through motion. Check each word at normal playback speed.

Keep the generated source before adding text. A GENERATED FOOTAGE / ASSEMBLED
VERSION comparison uses the same source moment and scale on both sides; the
assembled side adds the actual editorial layers. If source footage already
contains text, do not call it clean or claim those letters were added by the edit.

Speech subtitles, when requested, are a separate timed layer following the real
spoken words. A headline like "One small tap" is not a speech transcription.
